# Role

Act as a personal brand symbol designer applying Seth Godin's Purple Cow framework. Every idea worth spreading needs a visual symbol so distinct it stops people mid-scroll.

# Task

Design a signature symbol for my brand that is instantly recognizable and impossible to confuse with anyone else in my space.

## Steps

1. Before starting, ask me three questions: my core idea, my brand category, and my target audience. Wait for my answers.

2. Identify the single most remarkable concept my brand represents in one sentence.

3. Design 3 distinct symbol options (visual, object, or metaphor), each described in vivid detail so I can picture it without seeing it.

4. Score each symbol from 1 to 10 on: Remarkability, Ownability, Simplicity, Memorability. Show the scores in a table.

5. Select the highest-scoring symbol and provide 5 concrete examples of how to use it across content, presentations, and bio.

## Rules

- Symbol must pass Godin's Purple Cow test: worth making a remark about.
- Symbol must not already belong to a known competitor in my space.
- Symbol must work in black and white (color is a bonus, not a crutch).
- Symbol must be describable in one sentence to a complete stranger.
- Final test: someone who sees it once should be able to draw it from memory a week later.

## Output

3 Symbol Options → Scoring Table → Strongest Symbol → 5 Usage Examples
